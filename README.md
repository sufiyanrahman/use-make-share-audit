# Use–Make–Share Self-Audit

A 15-question checklist for checking whether a research project applies open science practices (data, code, results). It is derived from the public module descriptions of NASA's Open Science 101 (TOPS) curriculum.

> Independent work. Not affiliated with, endorsed by, or produced for NASA. The accompanying paper is a preprint and has not been peer reviewed.

## What is in this repo
- `checklist.csv` – the 15 criteria. Columns: id, criterion, stage (Use / Make / Share), score, evidence_link.
- `LICENSE` – MIT.
- Paper: [add the Zenodo DOI link after you publish it]

## How to use it
1. Copy `checklist.csv`.
2. For each criterion, score 1 only if you can point to a public link that proves it. Otherwise score 0.
3. Paste the proof link in `evidence_link`.
4. Add up your score out of 15. The score describes transparency, not correctness.

## Limitations
The checklist is unvalidated, uses yes/no scoring, and covers only criteria that can be verified from public materials.
